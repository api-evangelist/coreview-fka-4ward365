Released December 15 th , 2020 with the following features: Improved Governance [CoreAdmin, CoreReporting] The Adoption Campaigns list is now filtered by V-Tenant, so each operator only views campaigns inside their V-Tenant. The RBAC feature is central to CoreView in allowing control of the permissions that each Operator has. In defining control of those permissions, a further check has been added that allows verification that permissions are not overlapping.
