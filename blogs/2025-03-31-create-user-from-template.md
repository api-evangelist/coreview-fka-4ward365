As an operator, your role in the user onboarding process involves creating new users based on the templates assigned to you by Tenant Admins. This article provides guidance on how to effectively create users using these templates. Creating a user from a User Template Step 1: Select assigned template Navigate to “ Management actions ” and select the “ Create user from template ” action.
