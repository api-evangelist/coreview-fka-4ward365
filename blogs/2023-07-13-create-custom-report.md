CoreView provides two methods for generating “ Custom reports ”: By saving and applying filters to an existing report, and having it show up in your “ Custom reports .” By using the “ Create new custom report ” functionality, as explained below. Create a custom report The “ Create new custom report ” functionality allows you to create new custom reports, which will appear in your custom reports list. Follow this step-by-step guide to create one.
