In the Reconcile page , you can customize which results are displayed by using the following features : search , configuration filters, and show . The Configuration Type Filter allows you to select the configuration types you want to display among the various tabs . You can filter configuration types using the following methods: Enter text in the “ Filter by config types ” search bar, then select configuration types from the filtered checklist.
