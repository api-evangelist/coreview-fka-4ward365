Workflows menu Under the “ ACTION ” item “ Manage Workflows ” you can find the following sub-categories: Workflows This section lists all created Workflows, both active and draft. From here, you can perform various actions on Workflows , such as creating new ones or scheduling them to run using CSV files. Workflow executions queued Tenant administrators and Management operators have access to this report, which provides comprehensive visibility and control over queued Workflows.
