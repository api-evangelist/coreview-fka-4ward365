Please note that the “ Tenants ” section is not available in the Configuration Manager SaaS version. Onboarding is managed via CoreView or the PartnerApp. Whether you choose to install your tenant using user account authentication, or with a service principal only , Configuration Manager will also create a service principal in the tenant you're installing.
