The “ SharePoint item-level ” report provides detailed information for any SharePoint Online files and folders, including items with or without unique permissions. The report also includes the following properties: Content type : indicates the item’s type name as text, including any custom content type when applicable. Base name : shows whether the item is a file or a folder, even when the item uses a custom content type.
