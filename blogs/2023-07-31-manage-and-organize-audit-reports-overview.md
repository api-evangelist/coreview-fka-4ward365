Regardless of the type of Audit report you are working with, you can use several common features to manage and organize your report. Common to all Audit reports are these functionalities: Export Audit reports Save an Audit report as custom report Schedule an Audit report Moreover, nearly all Audit reports allow you to create custom policies , with the only exceptions being: ENTRA ID : Monthly sign-ins by users Monthly sign-ins by app Risk detections Sign-ins from anonymous IP addresses Sign-ins from unfamiliar locations Impossible travel to atypical locations Sign-ins protocols usage Coreview
