The “ Import ” functionality, which, as far as reports are concerned, is active only for “ Custom reports ”, allows you to import previously exported objects (in JSON format), and is therefore closely related to the “Custom reports” export functionality (this differs from the “ Export ” functionality available in all the other reports, which allows you to export data in CSV, Excel or PDF format). In other words, to import a custom report, an export must first have been carried out.
