This how‑to article shows how to view all the mailboxes a user has access to using CoreView. From the “Reports” section Under “ Reports ”, select “ Security ”, and then choose “ User mailbox security ”. Here, apply a filter to the “ Users with access ” column using the user principal name of the user for whom you want to view all mailbox access.
