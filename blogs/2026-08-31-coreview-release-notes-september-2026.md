September 15 enhancements IN THE SPOTLIGHT [COREY] Workflow execution in conversations: Corey now shows Workflow descriptions and can run suggested Workflows directly inside the conversation. When a Workflow is selected, Corey opens a preview of its run form. Inputs already provided in the prompt are prefilled, so administrators do not need to re-enter the same information.
