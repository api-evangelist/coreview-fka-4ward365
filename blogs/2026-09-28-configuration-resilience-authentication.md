To allow Configuration Resilience to back up configurations and deploy changes , each tenant installed on the platform requires an authentication method. Application authentication method Configuration Resilience supports application authentication . It requires a service principal in the tenant and authenticates as that service principal by using one of these credential types: Client secret: a password-like credential associated with the application registration in Microsoft Entra ID.
