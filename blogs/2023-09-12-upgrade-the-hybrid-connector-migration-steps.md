Step 1: Get your API key Navigate to the CoreView Portal and access:: “ Settings ” > “ My organization ” > “ On premises ” > “ On-premises configuration ”. Click the “ Edit ” button and note down your API key: You will need this API key later when setting up the Hybrid Connector 2019. Step 2: Deploy the Hybrid Connector Deploy the Hybrid Connector on your new server following the instructions in the Hybrid Connector deployment official documentation.
