This how-to explains how you can use CoreView to manage your Microsoft 365 environment with custom actions powered by the Microsoft Graph API . By leveraging the Microsoft Graph PowerShell SDK integrated within CoreView, you can create custom scripts that you can execute as management actions or as part of workflows . Important notice As of March 31, 2025, all legacy Azure AD (AzureAD module) and MSOnline PowerShell cmdlets have been retired by Microsoft.
