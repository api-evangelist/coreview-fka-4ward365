This article guides you to check and authorize the use of the Microsoft Graph module, necessary for utilizing: Custom actions Management actions Remediation of certain policies that use the Graph PowerShell module or Graph API endpoints. View permissions list To check if you have granted the permissions, go to: to “ Settings ” > “ My organization ” > “ App management ”. This section will initially appear empty, but once configured, you'll see all relevant details.
