Configuration Manager SaaS is hosted on CoreView's cloud infrastructure, so no access to Azure DevOps required. This article does not apply to Configuration Manager SaaS. To change which groups or users can install tenants, do the following: Access Azure DevOps Select the project with the desired tenants > “ Pipelines ” > “ Library ” Select the “ Security ” tab Press “ Add ” to add a user or group To install a tenant, the user or group must be granted Administrator rights To restrict installing tenants, the user or group should be granted Reader rights
