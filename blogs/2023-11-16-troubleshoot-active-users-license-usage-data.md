Problem If you're experiencing discrepancies in the active/inactive users (license usage) data in CoreView, this guide will help you troubleshoot the issue. Explanation CoreView relies on various sources like PowerShell, Exchange Web Services, Graph, Management API, and Azure AD Audit. However, data from these sources may not always synchronize perfectly, resulting in reporting differences.
