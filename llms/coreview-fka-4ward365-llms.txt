# CoreView (FKA 4ward365)

> CoreView (formerly 4ward365) is an enterprise Microsoft 365 governance, security, and automation platform. It secures the configuration, identity, and access layers of Microsoft 365 tenants and provides delegated administration, license management, reporting, and workflow automation. The CoreView Public API is secured with OAuth 2.0 / OpenID Connect (client-credentials) via regional API proxies, with a companion CoreFlow Workflow API.

## APIs

- [CoreView Public API — Authentication](https://help.coreview.com/api-authentication): OAuth 2.0 / OIDC client-credentials, regional API proxy hosts, documented scopes.
- [Run a Workflow via API (CoreFlow)](https://help.coreview.com/schedule-and-run-workflows/run-a-workflow-via-api): Trigger and monitor workflow automation runs.

## Identity

- [OpenID Configuration](https://identity.coreview.com/.well-known/openid-configuration): OIDC discovery (issuer, jwks, token/authorization/userinfo/introspection endpoints).
- Token endpoint: https://identity.coreview.com/connect/token (GOV: https://usidentity.coreview.com/connect/token)
- Scopes: customer.read/write, delegation.read/write, operator.read/write, platform.read, licensepool.read/write, license.read
